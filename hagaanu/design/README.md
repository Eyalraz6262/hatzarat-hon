# מסכי עיצוב — "כרטיס נסיעה"

השפה הוויזואלית של האפליקציה, בשפת השילוט של רכבת ישראל.
כל קובץ `.dc.html` הוא מסך אחד ברוחב 390×844.

| קובץ | מסך |
|---|---|
| `Onboarding.dc.html` | פריימר הרשאות — מיקום ברקע |
| `MapEmpty.dc.html` | מפה לפני בחירת יעד |
| `Main.dc.html` | בחירת יעד ורדיוס — המסך המרכזי |
| `Pass.dc.html` | מצב מזוין, בנוי ככרטיס נסיעה |
| `Alarm.dc.html` | מסך ההתראה |
| `Saved.dc.html` | יעדים שמורים |

`canvas.json` קובע את הפריסה על הקנבס ואת ההערות.

## המערכת

| | |
|---|---|
| דיו | `#14161C` — רקע |
| נייר | `#F2EDE4` — משטחי כרטיס |
| סיגנל | `#FF6B1A` — אקסנט יחיד |
| ברזל | `#6B7280` — קווי מסילה |

טיפוגרפיה: **Heebo** 900/800 לכותרות · **Assistant** לגוף · **IBM Plex Mono**
למספרים, כמו לוח יציאות. שלושתם ב-Google Fonts, כלומר ניתנים להטמעה
באפליקציה עצמה.

שלושה כללים שמחזיקים את השפה:

1. **פינות ישרות בלבד** — שילוט לא מעגל פינות.
2. **כתום אחד לכל מסך.** במסך ההתראה הוא לוקח את כל השטח, וזה עובד רק
   מפני שבכל שאר המסכים הוא מנה קטנה.
3. **אפס אימוג׳י** — כל סימן מצויר ב-SVG.

הקופי בכל המסכים נלקח מ-`src/i18n/translations/he.ts`, לא נכתב מחדש.

## עריכה

הקבצים כאן הם המקור. הקנבס המפורסם נבנה מהם, ותוצר הבנייה עצמו
(`*-screens.html`, ~2.5MB) לא נשמר בגיט — הוא נוצר מחדש מהמקור.
